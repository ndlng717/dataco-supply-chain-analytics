# Dataset

This project uses the **DataCo Smart Supply Chain for Big Data Analysis** dataset from Kaggle.

## Source

Kaggle dataset:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

## Files Used

- `DataCoSupplyChainDataset.csv` — transaction, customer, product, order, and shipping data
- `tokenized_access_logs.csv` — digital product access-log data
- `DescriptionDataCoSupplyChain.csv` — field descriptions / data dictionary

## Note

The two raw datasets are not stored in this repository because of their file size.

The original files can be downloaded directly from the Kaggle source above.

The data dictionary is included in this folder for reference.
